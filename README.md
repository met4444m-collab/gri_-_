# gri_-_
простой архиватор для windows, кликните правой кнопкой мыши на папку/файл и нажмите "добавить в архив" чтобы сделать архив. для просмотра архива достаточно нажать 2 раза левой кнопкой мыши на .gru архив и он откроется как обычная папка. чтобы распаковать надо зайти в архив и перетащить все файлы в нужную папку
